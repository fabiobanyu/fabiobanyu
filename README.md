I am a **Data Science undergraduate** at **Institut Teknologi Sumatera (ITERA)**. I have a deep fascination for turning complex, unstructured data into meaningful stories and robust predictive models. I specialize in building end-to-end data pipelines, from exploratory data analysis to deploying scalable machine learning models.

### 🚀 Featured Data Projects

> **[🍃 Hoya Leaf Disease Detection](https://github.com/fabiobanyu/Hoya-Leaf-Disease-Detection)** <br>
> An end-to-end Machine Learning pipeline utilizing **ResNet-50** and a **MobileNetV3 Guardian Model** to classify diseases on Hoya plants. Integrated with a **Neo4j Knowledge Graph** for intelligent treatment recommendations and deployed via Flask web interface.

> **[🚂 National Railway Traffic Forecasting](https://github.com/fabiobanyu/TUBES-ADW-Forecasting-Penumpang-KA)** <br>
> A comprehensive **Time-Series Analysis** project built with **R**. Forecasted national railway passenger traffic (2020-2025) to identify seasonal trends and future demand patterns using advanced statistical models.

> **[🚶‍♂️ Stochastic Mobility Analysis](https://github.com/fabiobanyu/TUBES-PemStok-Mobilitas-Mahasiswa)** <br>
> Applied **Markov Chain** modeling in **R** to analyze and predict the stochastic mobility patterns of university students based on survey data, uncovering short-term movements and steady-state probabilities.
